How to balance an equation

  1. Count the atoms of each element on both sides.
  2. Start with an element that is in only one substance on each side. Leave elements on their own, like O2 or H2, until last.
  3. Add a whole molecule where that element is short, then count again.
  4. Stop when every element matches, in the lowest whole numbers.

The same atoms are there before and after: they are only rearranged. That is why mass is conserved.

2H2O
Coefficient: the big number in front. It counts whole molecules, so 2H2O is two separate water molecules. Change this to balance.
Subscript: the small number after a symbol. It counts the atoms of that element inside one molecule. No number means one. Never change this.

Change a subscript

✗ Not allowed when balancing
Warning: chemically illegal!

A subscript is part of the formula. Changing it rebuilds the inside of the molecule, so it becomes a different substance with different properties. The equation might "balance", but it no longer describes the reaction.

Change the coefficient

✓ This is how you balance

A coefficient multiplies the whole formula. Each copy is a complete, unchanged molecule, so the substance stays the same: you just have more of it.
